# data/

| 目录 | 内容 | 是否入库 |
|---|---|---|
| `raw/` | 原始资料（典票库压缩包和解压后的文件）。只读，不要修改 | ❌ |
| `interim/` | `py -I tools/tg.py ingest` 生成的 UTF-8 文本和脚注 JSON | ❌（可再生成） |
| `templates/` | 结构化后的典票场景模板 | ✅ |
| `rules/` | 规则库 JSON | ✅ |
| `synthetic/` | 变异生成的合成样本 | ❌（可再生成） |
| `golden/` | 人工核验过的黄金评测集，只能放合成或编造的样本 | ✅ |

**真实工作票永远不得放进这里。** 见 `docs/07-合规与数据安全.md`。
