# ADR-0009 主界面：双击就打开的本机页面

- 状态：已采纳（2026-11-13，需求方要求）
- 关联：ADR-0007（报告页；本文改掉了它第 1 节“不做本机网页服务”的决定）、ADR-0008（模型模式）；T-021
- 涉及红线 5（运行时零联网）的例外范围，见第 3 节

## 背景

试用包做出来以后，用法是“把 .txt 拖到 `规则模式.bat` 或 `模型模式.bat` 上”。需求方的意见：要有主界面，用户打开就能直接用，不能让他装环境、配模型。

拖放方案对审票人确实不友好：

1. 要先把票面存成 .txt（记事本另存，还要选对编码），才能拖。他手上最顺的动作其实是“在系统里全选、复制”。
2. 选模式靠认两个批处理文件。
3. 模型模式要等十几秒，这期间只有一个黑窗口。
4. 审完一张，页面上没有“再审一张”的路。

ADR-0007 当时不选“本机网页服务”，理由是要常驻进程、要监听端口、红线 5 没留这个例外。现在需求方明确要主界面，这个取舍要重做。

## 决定

### 1. 形态：`票审.exe` 自己开一个只有本机能访问的页面

双击 `票审.exe`（不带参数）：程序在 `127.0.0.1` 上挑一个空闲端口开页面服务，用系统默认浏览器打开主界面。主界面里粘贴票面或选文件 → 选模式 → 点“开始预审” → 报告直接显示在页面里。

- 不新增依赖：页面服务用标准库自己写，一次处理一个请求，不开线程。
- 不需要安装任何东西：模型程序（llama.cpp 官方编译好的 CPU 版）和它要的运行库都在文件夹里，`票审.exe` 自己启动、自己关。
- 把票拖到 exe 图标上、命令行 `tg check` 这两条老路照旧能用。

没有选原生窗口，理由和 ADR-0007 一样：Win7 上要嵌 IE 内核、要写 `unsafe`，或者要引入一大串 GUI 依赖（在 1.77.2 上能不能离线构建都没有把握）。

### 2. 主界面怎么设计（审票人打开以后看到什么）

一页，两步，一个按钮：

1. **放入票面**：一个大文本框，直接粘贴；也可以选 .txt 文件或把文件拖进来（一次几张）。文件是 UTF-8 还是记事本默认的 ANSI（GBK）页面自己认，不让用户选编码。手头没有票时，可以点一张编造的示例票。
2. **选模式**：规则模式 / 模型模式两张卡片，各用一两句话说清楚差别和要等多久。这台电脑用不了模型模式时，卡片变灰并写明原因；默认选能用的最好的那个，记住上次的选择。
3. **开始预审**：之后页面左边是这一批票的列表（每张一句结论，颜色和报告页的结论条一致），右边就是原来的报告页（T-011～T-014，原样嵌进来，反馈区照常能用）。等待时显示“正在预审… N 秒”，模型第一次启动要等多久写在页面上。
4. “再审一张”回到第一步；“退出票审”关掉程序。

报告同时存到 `票审.exe` 旁边的 `报告` 文件夹，页面上写明存到了哪里。

页面仍按 IE11 能跑的写法（ES5，不用 fetch、不用 CSS 变量和 grid）。页面文件是 `rust/tg/src/ui.html`，编译进 exe，不是磁盘上的散文件。

### 3. 红线 5 的例外范围（门禁同步改）

红线 5 原文的例外是“连接本机 `127.0.0.1` 上的推理服务”。现在例外扩成“本机 `127.0.0.1`”这一个地址上的两件事：

| 文件 | 允许做的事 |
|---|---|
| `rust/tg/src/model.rs` | 启动本机模型程序，连它（ADR-0008） |
| `rust/tg/src/ui.rs` | 在 `127.0.0.1` 上监听，给主界面用 |

其它文件照旧禁止 `std::net`。门禁对这两个文件逐行检查：`bind` / `connect` 必须和 `Ipv4Addr::LOCALHOST` 写在同一行，不得出现别的地址、主机名解析、UDP。

“监听端口”比“一个 HTML 文件”更需要向安全审查解释清楚，所以页面服务要做到：

- **只绑 `127.0.0.1`**。同一网络里的其它电脑连不上。
- **一次运行一个随机口令**，放在地址里（`http://127.0.0.1:端口/口令/`）。地址不带对口令的请求一律当作不存在。这台电脑上的别的程序、浏览器里别的网页，不知道口令就调不了它。
- **核对 `Host`**：必须正好是 `127.0.0.1:端口`，防止别的网页借域名解析把请求绕进来。
- **不常驻**：关掉窗口或点“退出票审”就结束；不随系统启动，不装服务。
- 页面能让程序做的事只有四件：预审一段票面文本、列出示例票、读这次运行生成的报告、退出。不能读写任意文件：报告的文件名由程序清洗过（去掉路径和特殊字符），只写进 `报告` 文件夹。
- 请求正文限 4 MB；每个响应都带 `Cache-Control: no-store`。

### 4. 模型在主界面里的生命周期

第一次用模型模式预审时才启动模型程序，之后留着复用，直到程序退出——主界面是一段连续的使用，每张票都重新加载模型太慢。命令行和拖放仍然是“一次运行启动一回、跑完就关”。

启动失败不重试：记下原因，之后这次运行里的模型模式都按“没用成”出报告（报告和页面上都写明原因）。重新双击 `票审.exe` 才会再试。

## 没有解决的、要如实告诉用户的

1. **还是会有一个黑色的命令行窗口**，它就是程序本身，关掉它程序就退出。隐藏它要把 exe 改成窗口子系统，那样命令行用法就没有输出了；先不改，窗口里写清楚“用的时候不要关”。
2. **等待时没有真进度条**，只有读秒。页面服务一次只处理一个请求，预审期间答不了别的请求；要真进度就得开线程，不值得。
3. **模型模式在 Windows 7 上仍然用不了**（ADR-0008）。主界面本身和规则模式在 Win7 上应当能用，但**没有在 Win7 和 IE11 上实测过**。
4. 仍然只接受票面文本（粘贴或 .txt）。Word、Excel、PDF 不能直接拖，页面会提示“打开它，全选复制，粘贴进来”。
5. 报告存在 `报告` 文件夹里，里面有票面内容。它和票面一样只能留在内网电脑上（使用说明里写明）。

## 后果

- `AGENTS.md` 红线 5 的措辞按第 3 节更新；`tools/gate.py` 的放行文件从一个变成两个。
- 核心库新增 `ui` 模块，只放不碰网络的部分（解析请求、拼响应、核对口令、清洗文件名），可以单元测试。
- 试用包里不再放两个批处理；可执行文件改名为 `票审.exe`。
