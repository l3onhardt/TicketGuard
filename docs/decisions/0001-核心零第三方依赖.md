# ADR-0001 核心功能零第三方依赖

- 状态：已采纳
- 日期：2026-11-05

## 背景

目标环境是电网内网的办公电脑：

- 通常无法 pip 安装；
- 引入的每个依赖都要经过信息部门的安全审查；
- 最终要打包成单个 exe，依赖越多，体积和出问题的概率都越大。

## 决定

- 解析、规则引擎、报告这些核心功能**只用 Python 标准库**。docx 和 xlsx 直接按 OOXML（zip 加 XML）解析。
- 模型推理用 llama.cpp 官方提供的 `llama-server.exe`，作为一个独立进程，通过 `127.0.0.1` 上的 HTTP 调用。这样 Python 一侧不需要 `llama-cpp-python` 之类的扩展。
- 开发阶段的工具（比如训练、蒸馏用的 PyTorch）只出现在外网开发机上，不进入发布包。

## 代价

- 要自己处理 OOXML 的细节，比如合并单元格、编号列表。
- 旧格式的 .doc 和 .xls 解析不了，需要人工先另存为新格式。
