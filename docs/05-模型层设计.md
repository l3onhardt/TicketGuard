# 05 模型层设计（类 Jev 决策层）

## 1. 模型在系统里的位置

模型只回答两类问题，**从不生成文字**：

| 问题 | 题型 | 例子 |
|---|---|---|
| 场景匹配 | `choice` | 状态：票面的工作任务、地点、停电范围。选项：经过规则初筛后的 3～10 个候选典票场景。 |
| 措施等效 | `noul` | 状态：票面的全部安全措施，加上一条标准措施“断开 10kVxx 线 xx 开关终端面板上的操作电源空开”。问题：票面里是否存在与它等效的措施？ |
| （以后）票种适配 | `choice` | 根据作业内容判断应该用第一种票、第二种票还是书面布置记录票 |

请求和响应的形状对齐 Jev 的 System One 协议（`state` + 具名的 `questions` → 每道题一个概率分布）。见 `src/ticketguard/decision/base.py`。

## 2. 后端演进路线

| 阶段 | 后端 | 原理 | 预期效果 |
|---|---|---|---|
| M4a | `RuleBaseline` | 实体抽取 + 归一化（同义词表，比如“令克 = 跌落式熔断器”）+ 字面匹配；输出 0 或 1 的概率 | 标准写法的票能覆盖大部分；换个说法就会误报 |
| M4b | `LlamaCppBackend` + 现成的中文小模型 | 把问题拼成提示词，只做一次前向计算，读取各选项 token 的 logits，归一化成概率（和 SemIf / OpenJev 的做法一样） | 能处理换说法和缩写；零样本，需要校准 |
| M7 | `DistilledBackend` | 蒸馏 + 量化后的专用小模型 | 更快更准，置信度更可信 |

**选型原则**：

- 优先用国产开源底座（比如 Qwen 系列），中文能力好，过安全审查时也更好解释。
- 体量按 0.5B / 1.5B / 4B 三档实测，**选满足指标的最小档**。具体型号在 M4 时按当时能拿到的版本确定，并记录到 ADR。
- 格式用 GGUF，量化先试 Q4_K_M，精度不够再试 Q8_0。推理用 llama.cpp 官方 CPU 版。
- 社区的类 Jev 项目（Kev、SemIf/OpenJev、Laya 等）**只借鉴思路，不直接引入代码**（AGENTS.md 红线 6）。

## 3. 校准（必须做）

- 模型直接读出来的概率不可信。要在合成集和黄金集上拟合**温度缩放**（temperature scaling），把参数写进模型配置里。
- **每做一次量化、换一次模型，都要重新校准**。量化会让置信度变准或变不准，必须重新测。
- 指标：ECE、Brier 分数、可靠性曲线。见 `06-评测与验收.md`。
- 分流阈值：校准后的概率 ≥ τ_high 才能标红（error）；介于 τ_low 和 τ_high 之间标为“需人工复核”（warning）。τ 值要在黄金集上按“error 精确率 ≥ 90%”这个约束来选。

## 4. 蒸馏 + 量化（M7）

```
① 教师：本地运行较大的开源模型（比如 Qwen 27B / 32B 级别），放在有 GPU 的外网机器上
        只输入 L0 数据（合成票和编造的票），输出每道题的完整概率分布
        人工抽查 10% 的教师标签；有疑问的样本由业务人员裁定
② 学生：0.5B～1.5B 的模型 + LoRA；或者 300M 级的编码器 + 分类头
        训练目标：KL(教师分布 ‖ 学生分布) + 带硬标签的交叉熵
③ 量化：导出 GGUF Q4 / Q8（解码器路线）或 ONNX INT8（编码器路线）
④ 量化后重新校准，再在黄金集上回归测试，指标不能低于 M4b 的水平
```

**禁止**：

- 用任何境外 API 当教师，包括 TypeSafe Jev。原因有两个：数据出境，以及违反对方服务条款中禁止用输出训练竞品的约定。
- 用 L2 数据（真实工作票）在外网训练。

立项并进入内网之后，可以在内网用真实票（L2）做一轮微调和评测。这一步要由信息部门批准。

## 5. 性能预算（估算，M4 时实测验证）

| 后端 | 内存占用 | 单个问题 | 一张票（约 1 道 choice 题 + 15 道 noul 题） |
|---|---|---|---|
| RuleBaseline | < 100MB | < 10 ms | < 0.5 s |
| 0.5B Q4 | 约 0.6GB | 0.2～0.6 s | 3～8 s（相同前缀可以复用 KV 缓存） |
| 1.5B Q4 | 约 1.3GB | 0.5～1.5 s | 6～20 s（偏慢，需要优化：把多道题合并进一次前向计算） |

优化手段：把票面放在提示词前面作为共享前缀，复用 KV 缓存；只把规则没匹配上的措施交给模型。
