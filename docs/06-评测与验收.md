# 06 评测与验收

## 1. 数据集

| 数据集 | 内容 | 用途 |
|---|---|---|
| `typical` | 全部典票（约 135 张，第一期只用第一种票的 21 张） | **零误报回归测试**：典票上不允许出现任何 error |
| `synthetic` | 变异生成，每个场景 × 每种算子，若干张 | 检出率；分算子统计 |
| `golden` | 人工核验的 ≥ 200 张，其中 30% 是“换说法但合格”的票 | 精确率、校准、最终验收 |
| `real`（内网，以后） | 真实历史票，包括被打回的票 | 上线前的最终验证，只在内网运行 |

## 2. 指标

| 指标 | 定义 |
|---|---|
| 检出率（Recall） | 预期问题中被报出的比例。按问题类别 A～F 分开统计 |
| 精确率（Precision） | 报出的问题中真实存在的比例。error 和 warning 分开统计 |
| 典票误报数 | 在 `typical` 上报出的 error 条数 |
| 场景匹配 Top-1 / Top-3 准确率 | 选中正确典票场景的比例 |
| ECE / Brier | 模型判断的校准程度 |
| 自动处理率 | 置信度达到 τ_high、不需要人工复核的判断占比 |
| P95 耗时、峰值内存 | 在参考机器上测（i5 四核、8GB） |

## 3. 验收门槛

| 里程碑 | 门槛 |
|---|---|
| M2 规则库 | 典票误报 = 0；每条 active 规则在对应的合成样本上检出率 = 100% |
| M4 决策层 | 措施漏项检出率 ≥ 95%；error 精确率 ≥ 90%；场景匹配 Top-1 ≥ 90%、Top-3 ≥ 98%；单票 P95 ≤ 10 s |
| M6 验收 | 在黄金集上满足以上全部指标；需求方抽查 30 张票，问题清单“基本可用”的比例 ≥ 80% |
| M7 蒸馏 | 各项指标都不低于 M4；ECE ≤ 0.05；耗时或内存至少一项改善 30% 以上 |

## 4. 评测报告

`py -I tools/tg.py eval --suite golden` 输出 `reports/eval-<日期>.json` 和 HTML 文件，要包含：

- 各指标的值，以及 Wilson 95% 置信区间；
- 与上一次报告的差异；
- 误报和漏报的样本清单，方便逐条分析。

只有满足门槛，才能把规则或模型的状态改为 active，或者发布新版本。
