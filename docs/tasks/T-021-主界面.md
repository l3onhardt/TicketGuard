## 目标

审票人双击 exe 就能用：程序在本机 `127.0.0.1` 上开一个页面服务，用默认浏览器打开主界面；在页面里粘贴票面、选模式、点“开始预审”，报告显示在页面里。

设计依据：`docs/decisions/0009-主界面.md`，**先读**。页面本身（`rust/tg/src/ui.html`）已经由规划者写好，受保护，不要改；这张卡做的是它背后的服务。页面用相对地址调下面“接口”一节的五个地址，读它的脚本可以确认字段名。

## 一、核心库 `rust/ticketguard/src/ui.rs`（新文件，`lib.rs` 里加 `pub mod ui;`）

不碰网络，只做纯函数。接口照写：

```rust
/// 浏览器发来的一个请求。
pub struct Request { pub method: String, pub path: String, pub host: String, pub body: String }

/// 从连接上读一个请求。
pub fn read_request(stream: &mut impl std::io::Read) -> Result<Request, Error>;
/// 拼一个完整的响应（状态行、头、正文）。
pub fn response(status: u16, content_type: &str, body: &str) -> Vec<u8>;
/// 核对 Host 和口令，返回口令后面的那一段地址；对不上返回 None。
pub fn route<'a>(request: &'a Request, port: u16, token: &str) -> Option<&'a str>;
/// 把页面传来的名字洗成能当文件名用的主文件名。
pub fn safe_name(name: &str) -> String;
```

### `read_request`

1. 一直读到出现 `\r\n\r\n`。头部（含这四个字节）超过 16384 字节 → `Error("请求头太长")`。还没读到就结束了（读到 0 字节）→ `Error("请求不完整")`。
2. 第一行按空格分成三段：方法、地址、协议。不是三段 → `Error("请求不完整")`。`path` 是地址里 `?` 之前的部分。
3. 头的名字不分大小写。`Host` 的值（去掉首尾空白）进 `host`，没有就是空串。`Content-Length` 没有按 0；不是非负整数 → `Error("请求不完整")`；大于 4194304 → `Error("票面内容太大（超过 4 MB）")`。
4. 正文正好读 `Content-Length` 个字节（第 1 步多读到的字节算在内）。没读够就结束 → `Error("请求不完整")`。不是 UTF-8 → `Error("请求正文不是 UTF-8")`。
5. 读的过程中 io 出错 → `Error(format!("读取请求失败（{err}）"))`。

### `response`

```
HTTP/1.1 {status} {OK 或 Error}\r\n
Content-Type: {content_type}\r\n
Content-Length: {正文字节数}\r\n
Cache-Control: no-store\r\n
X-Content-Type-Options: nosniff\r\n
Connection: close\r\n
\r\n
{正文}
```

状态码 200 写 `OK`，其它都写 `Error`。

### `route`

`request.host` 必须正好等于 `127.0.0.1:{port}`，`request.path` 必须以 `/{token}/` 开头；都满足时返回后面剩下的部分（可以是空串），否则 `None`。

### `safe_name`

按顺序：

1. 这些字符各换成 `_`：`\ / : * ? " < > |` 和所有控制字符（`char::is_control`）。
2. 结尾是 `.txt`（不分大小写）就去掉这四个字符。
3. 去掉首尾的空白和 `.`。
4. 结果是空串 → `粘贴的票面`。
5. 超过 60 个字符只留前 60 个（按字符，不按字节）。

## 二、`rust/tg/src/main.rs` 的改动

1. `mod ui;`。命令表加 `ui`，`usage()` 里在 `check` 前面加两行：

   ```
       ui [--out 目录]
           打开主界面（直接双击 exe 也是这个）：在浏览器里粘贴票面、选模式、看报告
   ```

2. **不带参数启动**（双击）：不再打印用法说明，改为运行主界面（等于 `tg ui`）。出错时 `eprintln!` 原因，`wait_for_enter()`，返回失败。
3. 把 `check_ticket` 拆开，让“预审一段文本”能被主界面复用。新函数：

   ```rust
   /// 预审一段票面文本，写出 JSON 和 HTML 报告，返回 (HTML 路径, 报告)。不打印。
   fn check_text(text: &str, name: &str, out_dir: &Path, args: &Args, mode: &Mode)
       -> Result<(PathBuf, serde_json::Value), Error>
   ```

   `name` 是主文件名：报告写到 `{out_dir}/{name}.预审.json` 和 `{name}.预审.html`，传给 `build_report` 的来源名是 `{name}.txt`。`check_ticket` 改成：检查扩展名 → 读文件 → `check_text` → 打印摘要。**命令行和拖放的输出、报告内容不能变**（原有测试和规划者的端到端比对会查）。唯一的例外：模型复核失败时那句 `模型复核没有做成，这张票只用了规则：…` 继续由 `check_text` 里打印。
4. 把 `prepare_mode` 里“已经知道是哪种模式之后”的部分拆成 `fn start_mode(mode: &str) -> Result<Mode, Error>`（`mode` 是 `rule` / `model` / `auto`，行为和现在完全一样，包括两句 `println!`），`prepare_mode` 只负责从命令行和环境变量取值再调它。
5. `open_in_browser` 的参数类型改成 `&std::ffi::OsStr`（主界面要用它打开一个 `http://` 地址）；失败时的提示改成 `没能自动打开，请手动打开：{目标}`。

## 三、`rust/tg/src/ui.rs`（新文件）

```rust
/// 运行主界面，直到用户退出。
pub fn serve(args: &Args) -> Result<(), Error>
```

（`Args`、`Mode`、`check_text`、`start_mode`、`locate`、`open_in_browser` 都从 `crate::` 取；子模块能看到父模块的私有项，不用改成 `pub`。）

### 启动

1. 报告目录：`--out` 给了用给的；否则是 exe 所在目录下的 `报告`（`std::env::current_exe()` 失败 → `Error(format!("找不到程序自己的位置（{err}）"))`）。
2. `TcpListener::bind((Ipv4Addr::LOCALHOST, 0))`，失败 → `Error(format!("本机没有可用的端口（{err}）"))`。
3. 口令：32 个十六进制字符。不引入随机数库——用两个 `std::collections::hash_map::RandomState::new().build_hasher().finish()`，各按 `{:016x}` 写出来拼在一起（`RandomState` 的种子来自系统随机源）。
4. 打印（`{地址}` 是 `http://127.0.0.1:{端口}/{口令}/`）：

   ```
   票审 TicketGuard {版本}

   主界面已经在浏览器里打开。没有自动打开的话，把下面这行地址复制到浏览器的地址栏：
   {地址}

   用的时候请不要关掉这个窗口。用完了直接关掉它，或者点页面右上角的“退出票审”。
   ```

   版本是 `env!("CARGO_PKG_VERSION")`。然后 `open_in_browser(地址)`。

### 循环

一次处理一个连接，不开线程。对每个接进来的连接：

- 读超时 2 秒、写超时 10 秒。
- `read_request` 失败、设置超时失败、写响应失败：**丢掉这个连接，不打印，继续等下一个**。（浏览器会预先开几条不发数据的备用连接，也会中途断开；这些不是程序的错误，打印出来只会吓到用户。这是本卡明确允许的唯一一处丢弃错误，代码里用一句注释写明原因。）`accept` 本身出错同样处理。
- `route(&request, 端口, &口令)` 是 `None` → 404，`text/plain; charset=utf-8`，正文 `没有这个页面`。
- 否则按“接口”一节处理，写回响应。处理完 `quit` 的响应写出去之后，跳出循环，`serve` 返回 `Ok(())`（模型靠 `Drop` 结束）。

### 接口（`route` 返回的那一段地址）

JSON 响应的 `Content-Type` 都是 `application/json; charset=utf-8`，状态码都是 200（出错也是 200，正文里 `ok` 为 `false`）。键的顺序照写。

| 方法 地址 | 做什么 |
|---|---|
| `GET` 空串 | 主界面：`include_str!("ui.html")`，`text/html; charset=utf-8` |
| `GET status` | `{"version", "model", "model_note", "out_dir"}`，见下 |
| `GET examples` | `[{"name", "text"}, …]`：`locate("示例票面")` 目录里所有 `.txt`（扩展名不分大小写），按文件名排序，内容用现有的 `read_ticket` 读。目录不存在 → `[]`。读目录或读文件出错 → `{"ok": false, "error": 原因}` |
| `POST check` | 预审一张票，见下 |
| `POST quit` | `{"ok": true}`，然后结束循环 |
| `GET report/{k}` | 这次运行里第 k 份报告（从 0 起）的 HTML 文件内容，`text/html; charset=utf-8`。k 不是数字、没有这一份、文件读不出来 → 404 `没有这个页面` |
| 其它 | 404 `没有这个页面` |

**`status`**：服务里记着一个“模型状态”，初值是“还没启动过”。

| 情况 | `model` | `model_note` |
|---|---|---|
| 还没启动过，`locate("models")` 不是目录 | `missing` | `这个文件夹里没有 models，只能用规则模式` |
| 还没启动过，是目录 | `available` | 空串 |
| 启动过，成功（`Mode::Ready`） | `ready` | 空串 |
| 启动过，没成（`Mode::Failed(原因)`） | `failed` | 原因 |

`out_dir` 是报告目录（`display()`）。

**`check`**：正文是 `{"name": 字符串, "text": 字符串, "mode": "rule" 或 "model"}`。

1. 正文不是合法 JSON、三个键不是字符串、`mode` 不是这两个值 → `{"ok": false, "error": "请求的格式不对"}`。
2. `mode` 是 `model` 而且还没启动过：`start_mode("model")`，结果（`Ready` 或 `Failed`）记进模型状态，之后一直复用，**不再启动第二次**。`start_mode` 返回 `Err`（设置文件读不了）→ `{"ok": false, "error": 原因}`，模型状态保持“还没启动过”。
3. `name = safe_name(请求里的 name)`；`check_text(text, &name, 报告目录, args, 模式)`，其中模式：`rule` 用 `Mode::Rule`，`model` 用记着的那个。
4. 失败 → `{"ok": false, "error": 原因}`。
5. 成功 → 把 HTML 路径记进这次运行的报告列表（序号 k 从 0 起），返回：

   ```json
   {"ok": true, "name": "…", "number": "…", "level": "…", "headline": "…",
    "report": "report/{k}", "saved": "…", "model_note": "…"}
   ```

   `number` 是报告的 `ticket.number`（没有或为空写 `未填写`）；`level`、`headline` 取报告的 `verdict`；`saved` 是 HTML 路径的 `display()`；`model_note`：这次用的模式是 `Mode::Failed(原因)` 时是原因，其它情况是空串。

同名的票后审的覆盖先审的文件（两份都在报告列表里，指向同一个文件），不做改名。

### 网络只能在本机（门禁会查这个文件的全文）

- 每一处 `bind(` 都要和 `Ipv4Addr::LOCALHOST` **写在同一行**（`cargo fmt` 之后仍然在同一行）。
- 不得出现 `127.0.0.1` 以外的 IP、`localhost`、`SocketAddr`、`ToSocketAddrs`、`UdpSocket`。打印地址时用 `listener.local_addr()` 取端口号（`.port()`），不要把 `SocketAddr` 写进类型标注。

## 不做

- 不开线程、不做异步、不做长连接（每个响应 `Connection: close`）、不做分块传输。
- 不做进度查询接口、不做历史记录、不做设置页、不做“打开报告文件夹”。
- 不引入任何依赖。不改页面（`ui.html`）、不改报告页（`report.rs`）、不改 `model.rs`。
- 不给端口、口令、超时加命令行选项或环境变量（只有已有的 `--out`、`TG_NO_OPEN`）。
- 口令不对时不给任何提示页，一律 404。
