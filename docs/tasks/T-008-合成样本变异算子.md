## 目标

在典票的票面文本上做“故意改错”，生成带期望标签的合成样本，用来评测检出率和误报（评测脚本是下一张卡）。变异直接改**文本**，这样解析、规则、匹配、比对整条链路都会被测到。另有两个“换说法但合格”的算子，用来测误报。

## 接口（照写）

```python
# src/ticketguard/synth.py
Mutation = tuple[str, list[dict]] | None    # (变异后的文本, 期望发现)；不适用时返回 None

def crew_off(text: str, rng: random.Random) -> Mutation: ...
def time_swap(text: str, rng: random.Random) -> Mutation: ...
def plan_swap(text: str, rng: random.Random) -> Mutation: ...
def outage_wrong(text: str, rng: random.Random) -> Mutation: ...
def loc_strip(text: str, rng: random.Random) -> Mutation: ...
def drop_signer(text: str, rng: random.Random) -> Mutation: ...
def drop_category(text: str, rng: random.Random) -> Mutation: ...
def paraphrase(text: str, rng: random.Random) -> Mutation: ...
def rename_lines(text: str, rng: random.Random) -> Mutation: ...
OPERATORS: dict[str, Callable]   # 名称 → 函数，顺序同上
def generate(chunks: list[ScenarioChunk], per: int, seed: int) -> list[dict]: ...
```

命令行（加到 `__main__.py`）：

```
python -m ticketguard synth <典票文本.txt> [输出 jsonl，默认 data/synthetic/d1.jsonl] [--per 5] [--seed 0]
```
读文本 → `split_scenarios` → 只取 `section == "配电第一种工作票典型场景"` → `generate` → 每行一个样本写 JSONL（UTF-8，`ensure_ascii=False`）→ 打印 `已生成 N 个样本 → <路径>`。输出目录不存在就创建。

## 规则（由规划者确定，不要改）

下文 `DT` 指日期时间正则 `\d{4}\s*年\s*\d{1,2}\s*月\s*\d{1,2}\s*日\s*\d{1,2}\s*时\s*\d{1,2}\s*分`。“在含 X 的行里替换”指：找到**第一个**含 X 的行，只替换这一行里的**第一处**匹配；找不到这样的行、或者这一行里没有可替换的内容（替换后没变化），算子返回 `None`。

| 算子 | 做法 | 期望发现 |
|---|---|---|
| `crew_off` | 在含 `总人数共` 的行里，把 `总人数共\s*(\d+)` 的数字加上 `rng.choice([1, 2])` | `[{"rule_id": "R-CREW-001"}]` |
| `time_swap` | 在含 `工作票接收人签名：` 的行里，把第一个 `DT` 换成 `2000年01月01日00时00分` | `[{"rule_id": "R-TIME-001"}]` |
| `plan_swap` | 在全文里找第一处 `自\s*(DT)(.*?)至\s*(DT)`，把两个时间对调，结果写成 `自<原至时间><中间部分>至<原自时间>` | `[{"rule_id": "R-TIME-002"}]` |
| `outage_wrong` | 在含 `停电设备或线路名称：` 的行里，把该标签之后的内容整体换成 `35kV虚构站10kV虚构线` | `[{"rule_id": "R-LOC-002"}]` |
| `loc_strip` | 以 `工作地点或设备（注明` 开头的行的**下一行**，在第一个 `|` 之前的部分里删掉所有变电站（`\d+kV[^，、；。|]*?站`）；下一行没有 `|` 或没删掉任何东西时返回 `None` | `[{"rule_id": "R-LOC-001"}]` |
| `drop_signer` | 在含 `工作票接收人签名：` 的行里，把 `(工作票接收人签名：[\s　]*)[^\s　/（(]+` 换成 `\1/` | `[{"rule_id": "R-REQ-002"}]` |
| `drop_category` | 以 `调度或设备运维单位负责的安全措施` 开头的行起，连续 5 行是五类措施栏。挑出“第一个 `|` 之后、第一个 `：` 之后的内容不只是 `无`”的行（判断：内容匹配 `[\s　/]*无[。.]?[\s　]*` 时算“只是无”），用 `rng.choice` 选一行，把这一行改成 `<第一个 | 之前的部分>|<栏目标签>：无`。类别按 T-003 的关键字表（应拉 / 应投切 / 接地 / 标志牌 / 保留或邻近）由标签确定。找不到起始行或没有可选行时返回 `None` | `[{"rule_id": "CMP-MISSING", "category": 类别}]` |
| `paraphrase` | 从 `[("合闸压板", "合闸连接片"), ("令克", "跌落式熔断器"), ("刀闸", "隔离开关"), ("空开", "空气开关")]` 中挑出前者在文本里出现的对（保持这个顺序），`rng.choice` 选一对，全文替换；没有可选的返回 `None` | `[]` |
| `rename_lines` | 找出全文所有 `10kV([^\s，,、；;。:：/kV“”（）()|]{1,6}?线)` 的线路名（第 1 组，去重），按长度从长到短排序（同长度按字符串升序），第 i 个（从 1 起）全文替换成 `虚构{i}号线`；一个都没有时返回 `None` | `[]` |

**`generate(chunks, per, seed)`**：`rng = random.Random(seed)`，整个生成过程共用这一个 rng。按 chunk 顺序、再按 `OPERATORS` 顺序，每个算子最多调用 `per` 次：返回 `None` 就停止这个算子；生成的文本在“本 chunk + 本算子”里重复的，丢弃（不计数也不报错）。样本格式：

```json
{"id": "syn-D1-S03-crew_off-0", "base_scenario": "D1-S03", "mutations": [{"op": "crew_off"}],
 "ticket_text": "...", "expected_findings": [{"rule_id": "R-CREW-001"}]}
```
`base_scenario` 为 `f"D1-S{int(chunk.number):02d}"`；`id` 末尾的序号是该算子在该 chunk 中**保留下来**的第几个样本（从 0 起）。

## 不做

- 不在 `Ticket` 对象上变异，不调用解析器和审查流水线（评测是下一张卡）。
- 不做 `weaken_measure`、`wrong_side`、`swap_type`、`role_conflict`、`drop_monitor`、`rename_device`（`docs/03` 里列的其他算子，等有对应的规则或模型再做）。
- 不写黄金集，不加 `verified_by` 字段。

## 验收

- `tests/test_t008_synth.py`（受保护）全部通过。它会对两张合成夹具票的每个算子做端到端检查：变异后的票过 `review_text`，期望的问题必须报出来；换说法的两个算子不得新增任何问题。

## 规模参考

参考实现约 95 行。在 21 张真实典票上（`--per 5`）生成 266 个不重复样本；对应的端到端检出率 99.3%，换说法类算子零误报。
