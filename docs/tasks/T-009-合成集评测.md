## 目标

把 T-008 生成的合成样本逐张送进审查流水线（`review_text`），统计每种变异算子的**检出率**（带 Wilson 95% 置信区间）、**意外发现**（误报的上界）和**场景命中**，并列出漏检和意外发现的清单，供人逐条看。

## 接口（照写）

```python
# src/ticketguard/evaluate.py
def wilson(k: int, n: int, z: float = 1.96) -> tuple[float, float]: ...
def evaluate(samples: list[dict], originals: dict[str, str], rules: list[dict],
             templates: list[dict], lexicon: dict) -> dict: ...
```

- `samples`：T-008 的样本（字段见 T-008 卡片）。
- `originals`：`base_scenario` → 原始典票文本。

命令行（加到 `__main__.py`）：

```
python -m ticketguard eval <典票文本.txt> [样本 jsonl，默认 data/synthetic/d1.jsonl]
       [--out 默认 reports/eval-<今天 YYYY-MM-DD>.json] [--templates 默认 data/templates/D1]
       [--rules 默认 data/rules] [--lexicon 默认 data/rules/lexicon.json]
```
读典票文本 → `split_scenarios` → 只取 `section == "配电第一种工作票典型场景"` → `originals = {f"D1-S{int(c.number):02d}": c.text}`；读样本（每行一个 JSON，跳过空行）；加载规则、模板、词表 → `evaluate` → 报告写成 JSON（UTF-8，`ensure_ascii=False`，`indent=2`，输出目录不存在就创建）。然后打印：

```
<算子>：样本 S，场景命中 T，检出 D/E，意外发现 U          ← 每个算子一行，按报告里的顺序
合计：样本 S，检出率 R（95% 置信区间 (a, b)），意外发现 U → <输出路径>
```

## 规则（由规划者确定，不要改）

**Wilson 区间**：`n == 0` 返回 `(0.0, 0.0)`；否则 `p = k/n`，`d = 1 + z²/n`，`c = (p + z²/(2n)) / d`，`h = z·sqrt(p(1-p)/n + z²/(4n²)) / d`，返回 `(round(c-h, 4), round(c+h, 4))`。

**同一个问题的认定**（`key`）：发现的 `scenario_id` 不为空（措施比对类）时，key 为 `(rule_id, evidence)`，否则为 `(rule_id,)`。不能按提示文字比对：比对类的提示文字里带匹配度，换个线路名，匹配度就变了，但还是同一个问题。

**命中一条期望**（`hit(f, e)`）：`f.rule_id == e["rule_id"]`；如果 `e` 带 `category`，还要求 `f.message` 里含 `“<category>”栏`（中文引号）。

**每张样本**：
1. `r = review_text(样本文本, ...)`，`got = r.findings`。
2. **新发现**：拿原票（`originals[base_scenario]`，原票的审查结果整个评测只算一次）各 key 的出现次数，按 `got` 的顺序逐条扣减：还有余额就扣 1，否则这条算新发现。
3. **检出**：每条期望，只要 `got` 里**任意一条**（不限于新发现）命中它就算检出，否则记一条漏检 `{"id": 样本id, "expected": 期望}`。原票已有的问题照样算检出。
4. **意外发现**：新发现里不命中任何期望的，每条记 `{"id", "rule_id", "message"}`。
5. **场景命中**：`r.candidates[0][0] == base_scenario` 记 1。
6. 计入算子 `mutations[0]["op"]` 的统计。

**报告**（键的顺序照写，测试会检查）：

```python
{"samples": N, "top1": 场景命中合计, "expected": 期望合计, "detected": 检出合计,
 "recall": round(detected/expected, 4) 或 None（expected 为 0）,
 "recall_ci95": wilson(detected, expected) 或 None,
 "unexpected": 意外发现条数, "by_operator": {算子: 统计}, "misses": [...], "unexpected_findings": [...]}
```
每个算子的统计：`{"samples", "top1", "expected", "detected", "unexpected", "recall", "recall_ci95"}`，`recall` 和 `recall_ci95` 的算法同上。`by_operator` 按算子在样本里**首次出现**的顺序。

## 不做

- 不算精确率（precision）。合成集里每张样本都有错，算精确率没有意义；误报看“意外发现”，以及 `paraphrase`、`rename_lines` 这两个合格算子。
- 不做黄金集，不画图，不做 HTML。
- 不并行，不缓存审查结果（除了原票只算一次）。
