# 09 术语表

标注“待确认”的条目是推测，写代码时不要当作事实。

| 术语 | 含义 | 代码中的注意点 |
|---|---|---|
| 两票 | 工作票和操作票 | |
| 配电第一种工作票 | 需要高压配电设备停电，或者需要做安全措施的工作 | 第一期的重点票种，编号格式为 `…-P1-…` |
| 配电第二种工作票 | 高压设备不停电，与带电部位保持规定安全距离的工作 | |
| 带电作业工作票 | 带电作业（绝缘杆作业法、绝缘手套作业法、综合作业法） | 编号格式为 `…-P3-…`；必须设专责监护人 |
| 紧急抢修工作票 | 需要高压停电或做安全措施的抢修 | 变更负责人时要重新办票 |
| 书面布置记录票 | 低压工作，以及满足安全距离的部分简单工作 | 高压抢修用紧急抢修票，低压抢修用书面布置记录票 |
| 一级 / 二级动火工作票 | 动火作业 | 有效期分别为 24 小时和 120 小时；签发人不得兼任负责人 |
| 操作票 | 倒闸操作 | 一份操作票只能填一个操作任务（有例外情形） |
| 典票、典型票库 | 各典型场景的标准样票 | 本项目的“标准答案” |
| 工作负责人（监护人） | 对作业现场负总责，并负责正确完整地填写工作票 | |
| 工作票签发人、会签人 | 审核并签发工作票 | |
| 工作票接收人 | 设备运维单位接收工作票的人，对票面内容有疑问应当提出 | **本系统的主要用户** |
| 工作许可人 | 落实运维单位负责的安全措施，并许可开工 | **本系统的主要用户** |
| 专责监护人 | 由签发人或负责人指定，全程专职监护；需要在票面特定位置注明 | 带电作业必须设置 |
| 专人监护 | 针对某个关键步骤或特殊场所临时安排的监护；不需要写在票面上 | 不要和专责监护人混淆 |
| 两种人 / 三种人 | 签发人、负责人、许可人等需要具备资格的人员类别 | 资质要到智慧安监系统核验（第一期不做） |
| 双重名称 | 设备名称加设备编号，比如“四镇 01 开关” | 格式校验 |
| 起止杆号 | 作业线路段的起始和终止杆塔编号 | |
| 小号侧 / 大号侧 | 杆号较小的一侧和较大的一侧，用来描述接地线的装设位置 | 实体抽取的字段 |
| 刀闸 | 隔离开关 | 同义词 |
| 令克 | 跌落式熔断器 | 同义词 |
| PT | 电压互感器 | “拉开 PT 令克”是断开合闸二次回路的方式之一 |
| 合闸二次回路 | 自动化开关的合闸控制回路，包括操作电源空开、合闸压板、PT 令克 | 停电检修时至少要断开一种 |
| X 延时 | 电压时间型馈线自动化中，终端得电后延时合闸的时间 | |
| 开闭所 | 配电开关站 | |
| 公变 / 专变 | 公用配电变压器 / 用户专用变压器 | |
| 台架变 | 安装在杆塔台架上的配电变压器 | |
| 可能来电的电源 | 电网侧电源，以及光伏、储能、发电机等可能反送电的电源 | 措施比对规则 R-SRC-001 |
| 3Y | **待确认**：推测是“三遥”（遥测、遥信、遥控）自动化设备 | |
| 分组工作派工单 | 把一张主票的工作分成几组执行时使用 | 和“同一检修申请单下的多张工作票”不同 |
| 智慧安监系统 | 用来核验人员资质的内部系统 | 第一期不对接 |
| 安规（配电） | 《中国南方电网有限责任公司电力安全工作规程 第 3 部分：配电》 | 条款依据的主要来源 |
| 释义 | 安规的官方释义 | |
| 工作票实施规范 | 《工作票实施规范 第 3 部分：配电》 | |
